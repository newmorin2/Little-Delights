# Little Delights Coffee Shop 

A modern, responsive coffee shop website built with React and Bootstrap. Little Delights is designed to create a warm and welcoming online experience where customers can explore the cafe's menu, learn about its story, and get in touch.

## Features

- **Responsive Navigation:** A responsive navbar with a collapsible mobile menu.
- **Hero Section:** A welcoming introduction with a coffee-themed background and a call-to-action button.
- **Menu Section:** Displays coffee, pastries, meals, and drinks with their prices, categories, images, and availability.
- **Our Story Section:** Introduces the cafe's values and approach to coffee and baking.
- **Contact Section:** A contact form that allows visitors to send inquiries.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Contact Form:** Functional contact form submission.
- **Modern Styling:** A warm color palette, elegant typography, and clean layouts.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap 5

## Getting Started

### Prerequisites

Ensure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/newmorin2/Little-Delights
   ```

2. Navigate to the project directory:

   ```bash
   cd little-delights
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local development URL provided by Vite in your browser.

## Responsive Design

The website adapts to different screen sizes:

- **Desktop:** Full navigation menu, side-by-side hero content, and horizontal feature strips.
- **Tablet:** Adjusted image heights, and spacing.
- **Mobile:** Collapsible navigation, vertically stacked sections, and a simplified hero feature strip.
